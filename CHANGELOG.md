## [0.1.0]

- CLI Node.js per Git e Bitbucket Data Center, con configurazione globale e credenziali sicure per piattaforma.
- Diagnostica locale e remota, risoluzione del repository dal remote Git e output JSON versionato.
- Ricerca, consultazione, creazione personalizzabile e merge di Pull Request, con anteprime e controlli preventivi.
- Completamento opzionale dei task e cancellazione condizionata del source dopo un merge confermato.
- Template delle descrizioni, rilevamento di PR aperte equivalenti e apertura facoltativa nel browser.
- Distribuzione tramite tarball con Commander incluso e installazione da Git.
- Versione CLI e flusso di release da tag con tarball verificato e checksum SHA-256.
